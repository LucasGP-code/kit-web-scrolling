Angioplastia coronaria

Información general sobre el procedimiento. La indicación y preparación definitiva las determina el equipo médico tratante según cada caso.

¿Qué es?

La angioplastia coronaria es un procedimiento de cardiología intervencionista que se utiliza para tratar el estrechamiento u obstrucción de una arteria coronaria, con el objetivo de restablecer el flujo de sangre hacia el músculo cardíaco.

¿Para qué se utiliza?

Se indica en pacientes con enfermedad coronaria diagnosticada, cuando una o más arterias del corazón presentan una obstrucción significativa que limita el flujo sanguíneo. La decisión de realizarla depende siempre de una evaluación médica individual, habitualmente luego de una coronariografía diagnóstica.

¿Cómo se realiza, en términos generales?

Se accede a la arteria a través de una punción, generalmente en la muñeca o en la ingle, con anestesia local. Mediante un catéter se llega hasta la zona obstruida y se utiliza un pequeño balón para dilatar la arteria; en muchos casos se coloca además un stent para mantenerla abierta. El procedimiento se realiza en una sala equipada especialmente para este tipo de estudios.

Preparación habitual

La preparación específica la indica el equipo tratante antes del procedimiento (ayuno, medicación habitual, estudios previos, documentación a llevar). Podés consultar las indicaciones generales de preparación para estudios, que siempre se complementan con las indicaciones puntuales de tu médico.

¿Qué sucede después?

Habitualmente se indica un período de observación e internación breve para control. El equipo médico brinda recomendaciones específicas sobre reposo, medicación y controles posteriores, adaptadas a cada paciente.

Preguntas frecuentes
